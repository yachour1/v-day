Surpriiise ! 💖
Une page web interactive et mignonne pour faire sourire quelqu'un de spécial. Le bouton "Oui" grandit à chaque fois que l'on clique sur "Non" — avec des cœurs, des GIFs personnalisables, de la musique et des petits messages tendres.

Comment personnaliser votre surprise
Forkez ce projet : Cliquez sur le bouton "Fork" en haut à droite pour créer votre propre copie.

Activez le site : Allez dans Settings > Pages. Dans Source, sélectionnez la branche main et cliquez sur Save. Attendez environ 2 minutes.

Personnalisez le contenu : Cliquez sur les fichiers (comme index.html) et utilisez l'icône crayon pour modifier les textes, les questions ou changer les GIFs.

Changez la musique : Remplacez simplement le fichier audio dans le dossier music/ par votre chanson préférée.
